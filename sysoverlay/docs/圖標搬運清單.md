## 2. 新增 IconKind（來自 Quel'Thalas）

### 2.1 导航图标（来自 `qt/src/icon/chevron_*.rs`）

| 新增 IconKind | 对应 Quel'Thalas 函数 | SVG viewBox | 用途 |
|---|---|---|---|
| `ChevronUp` | `Icon::chevron_up_16_regular()` | 16×16 | Stepper `＋` 按钮内部 |
| `ChevronDown` | `Icon::chevron_down_16_regular()` | 16×16 | Stepper `−` 按钮内部 |
| `ChevronRight` | `Icon::chevron_right_20_regular()` | 20×20 | Disclosure 折叠箭头（现有用 `>` 线段代替） |

**SVG Path 取值规则（⚠️ 高智审阅修正版，S6 实际执行流程）：**

> ❌ **禁止使用本文档早期版本里手抄的 path 字符串**——那是草稿，含错误坐标。
> ✅ **唯一真值 = Quel'Thalas 源文件**：打开 `qt/src/icon/chevron_up.rs`、
> `chevron_down.rs`、`chevron_right.rs` 等，取其中的 `d` 字符串。
>
> **坐标系归一化（必做步骤）**：本项目 `icons.rs` 的绘制管线假设 viewBox=1024
> （`VIEW` 常量），而 Fluent 图标是 16/20/24 空间。取到 `d` 后必须把**所有坐标
> （含弧半径）乘以 `1024 / viewBox边长`**：
>
> | 源 viewBox | 缩放系数 |
> |---|---|
> | 16×16 | ×64 |
> | 20×20 | ×51.2 |
> | 24×24 | ×42.667 |
>
> 乘完写入 `icons_svg/*.svg`（viewBox 同时改为 `0 0 1024 1024`）。
> 归一化精度由既有测试兜底：`every_icon_stays_within_viewbox`（越界/截断）
> + `all_icons_parse_non_empty`。
>
> 解析器已支持椭圆弧（S6 前置，`icons.rs parse()` 新增 A/a → 三次贝塞尔升阶，
> W3C F.6.5 算法 + 3 个锁定测试），归一化后的 Fluent path 无需预处理。
>
> 参考锚点（chevron_down_16_regular 源 `d` ×64 后 = `M201.6 361.6c12.8-12.8 32-12.8 44.8 0L512 626.56l265.6-264.96a32 32 0 0 1 44.8 44.8l-288 288a32 32 0 0 1-44.8 0l-288-288a32 32 0 0 1 0-44.8Z`）

## 3. 执行步骤（S6 低智模型照此执行）

### 步骤 1：在 `settings/icons_svg/` 新建 SVG 文件

每个图标新建一个文件，内容为上述**直接复制**的 SVG 代码。

### 步骤 2：在 `icons.rs` 添加 IconKind 变体

```rust
// 在 IconKind 枚举添加：
ChevronUp,
ChevronDown,
ChevronRight,
Copy,
Dismiss,
Checkmark,
```

### 步骤 3：更新 `SOURCES` 数组

在 `SOURCES` 数组末尾添加对应的 `include_str!`：
```rust
const SOURCES: [&str; 11] = [
    // ... 现有 8 个 ...
    include_str!("icons_svg/chevron_up.svg"),
    include_str!("icons_svg/chevron_down.svg"),
    include_str!("icons_svg/chevron_right.svg"),
    // 如需更多：copy, dismiss, checkmark
];
```

### 步骤 4：更新 `PATHS` 缓存数组大小

```rust
static PATHS: OnceLock<[Vec<PathSeg>; 11]> = OnceLock::new();
```


## 4. SpinButton 箭头替代（立即可用）

现有 `paint_stepper` 用手绘线段画 `＋` 和 `−`：
```rust
// widget.rs:624-628（现有代码）
let k = super::layout::s(dpi, 5) as f32;
let my = (minus.t + minus.b) / 2.0;
let mx = (minus.l + minus.r) / 2.0;
gfx.line(rt, mx - k, my, mx + k, my, cm, 1.5);  // − 横向线段
// ...
gfx.line(rt, px_ - k, py_, px_ + k, py_, cp, 1.5);  // ＋ 横
gfx.line(rt, px_, py_ - k, px_, py_ + k, cp, 1.5);  // ＋ 纵
```

**替换为**：使用 `Icon::chevron_up_16_regular()` 和 `Icon::chevron_down_16_regular()` 的 path geometry，按 `spin_button.rs` 的绘制方式贴入。

# S2 控件移植模板（Switch 试点）

> 本文档是 S2 的**交接物**，是低智模型执行 S3/S4 铺开时的**唯一执行依据**。
> 由高智模型（我）在 S2 完成后产出，低智模型严格按此模板逐控件替换。

---

## 1. 移植核心原则

1. **只移植绘制代码，保留现有交互管线**——`mod.rs` 的 `on_click_toggle`/`dispatch`/`apply_config` 不动
2. **用现有 `anim_v` 弹簧驱动**，Fluent WAM 动画参数换算为等效 `motion.rs` 弹簧常量
3. **每步替换即删旧路径**，不留双套代码
4. **红线下禁止触碰**（见 §6）

---

## 2. Switch 绘制替换对照（可直接抄）

### 现有绘制（widget.rs `paint_toggle`）

```rust
// widget.rs:470-493
fn paint_toggle(rt: &ID2D1HwndRenderTarget, gfx: &mut Gfx, state: &WidgetState,
    dpi: u32, t: &Theme, r: RectF)
{
    let tw = super::layout::s(dpi, 34) as f32;   // 现有 34×20
    let th = super::layout::s(dpi, 20) as f32;
    let r = RectF::new(r.r - tw, (r.t + r.b - th)/2.0, r.r, (r.t + r.b + th)/2.0);
    let k = state.anim_v.clamp(0.0, 1.0);         // 弹簧值（0..1）
    let radius = r.h() / 2.0;
    hover_overlay(gfx, rt, t, r, radius, state.hover_t);
    let fill = lerp_color(c(t, t.toggle_off), c(t, t.toggle_on), k);
    let stroke = lerp_color(c(t, t.toggle_off_stroke), c(t, t.toggle_on), k);
    gfx.fill_round(rt, r, radius, fill);
    gfx.stroke_round(rt, r, radius, stroke, 1.0);
    let m = super::layout::s(dpi, 2) as f32;
    let d = r.h() - 2.0 * m;
    let kx = r.l + m + (r.w() - 2.0*m - d) * k;  // 旋钮位置
    gfx.fill_ellipse(rt, RectF::new(kx, r.t+m, kx+d, r.b-m), c(t, t.knob));
}
```

### 替换为 Fluent Switch（直接替换整个函数体，保留函数签名）

```rust
// widget.rs:470 新版（贴入后删除旧代码）
fn paint_toggle(rt: &ID2D1HwndRenderTarget, gfx: &mut Gfx, state: &WidgetState,
    dpi: u32, t: &Theme, r: RectF)
{
    // ── Fluent Switch 几何（switch.rs State 方法直译）──
    let track_w = 40.0f32;       // Fluent 固定值，不走 DPI 缩放（已是逻辑像素）
    let track_h = 20.0f32;
    let thumb_radius = track_h/2.0 - 1.0 - 2.0; // = 7（stroke_thin=1, inset=2）
    let radius = track_h / 2.0;

    // 轨道右对齐（与旧实现一致）
    let r = RectF::new(r.r - track_w, (r.t + r.b - track_h)/2.0, r.r, (r.t + r.b + track_h)/2.0);
    let k = state.anim_v.clamp(0.0, 1.0); // 弹簧值（0..1）

    hover_overlay(gfx, rt, t, r, radius, state.hover_t);

    // ── 颜色（WAM cubic-bezier → 弹簧，k 直接用 anim_v）──
    // switch 轨道填充：关=透明，开=brand 色
    let checked_fill = lerp_color(c(t, t.toggle_off), c(t, t.toggle_on), k);
    // switch 轨道描边：关=neutral_stroke_accessible，开=透明
    let unchecked_stroke = c(t, t.toggle_off_stroke);
    let stroke_a = 1.0 - k; // 描边透明度随开态递减
    let stroke_color = ColorF::rgba(
        unchecked_stroke.r(), unchecked_stroke.g(), unchecked_stroke.b(),
        stroke_a * unchecked_stroke.a(),
    );

    // 旋钮颜色：关=knob(白)→开=白（不变）
    let knob_color = c(t, t.knob);

    // 绘制轨道（填充）
    gfx.fill_round(rt, r, radius, checked_fill);
    // 绘制轨道（描边）
    gfx.stroke_round(rt, r, radius, stroke_color, 1.0);

    // 绘制旋钮
    let m = 2.0f32; // thumb_inset
    let d = track_h - 2.0 * m;  // = 16（旋钮直径）
    let kx = r.l + m + (r.w() - 2.0*m - d) * k; // 位置插值
    gfx.fill_ellipse(rt, RectF::new(kx, r.t+m, kx+d, r.b-m), knob_color);
}
```

**关键差异说明：**
| 项目 | 旧实现 | Fluent Switch |
|---|---|---|
| 轨道宽高 | 34×20（layout 缩放） | 40×20（固定 DIP） |
| 填充色 | 关=toggle_off(灰)→开=toggle_on(绿) | 关=off→开=brand(蓝) |
| 描边 | 关=off_stroke→开=on(透明) | 关=neutral_stroke_accessible→开=透明 |
| 弹簧 | `anim_v` 0..1 | `anim_v` 0..1（直接复用） |

## 3. `anim_v` 弹簧参数（Fluent WAM → motion.rs 等效）

Fluent WAM 参数（switch.rs）：
- `duration_normal = 0.167s`
- `curve_easy_ease = [0.16, 1.0, 0.3, 1.0]`

等效 Apple Spring 参数（`motion.rs`）：
```
K_UI = 246.74, C_UI = 31.416  ← 已存在，直接复用
```
**不需要新建参数**——`duration_normal=0.167s` 对应 response=0.4s（Apple ζ=1.0），恰好是 `K_UI/C_UI`。

## 4. 执行步骤（S3/S4 铺开时照此执行）

### 按钮（ButtonWidget）

**旧绘制**：`paint_button` in widget.rs:538-576
**替换为**：Quel'Thalas `button.rs` → 提取 `paint()` 中的几何 + 颜色逻辑
**Fluent 关键值**：
- `border_radius_medium = 4.0`（旧实现=7px → **改为 4**）
- Primary: `color_brand_background` / hover: `color_brand_background_hover`
- Secondary: `color_neutral_background1` / hover: `color_neutral_background3_hover`
- 字号：Primary `font_size_base300`(14)，Secondary `font_size_base200`(12)

**步骤**：
1. 用上表情对照表替换 `paint_button` 中的颜色值
2. 圆角常量从 `layout::s(dpi, 7)` 改为 `4.0`（直接写死，因为 Fluent 值是 DIP）
3. 保留 `ButtonKind::Link` 链接样式（Quel'Thalas button 无对应，简化为仅文字+accent 色）

### 步进器（StepperWidget）

**旧绘制**：`paint_stepper` in widget.rs:580-634
**替换为**：Quel'Thalas `spin_button.rs` → 提取 stepper gutter + chevron_up/down 绘制
**Fluent 关键值**：
- Steppers: 16×16 chevron icon，fill `color_neutral_foreground3`
- Disabled: `color_neutral_foreground_disabled`（降透明度）
- 字段高：32dp（Small=24，Large=40）

**步骤**：
1. 替换 chevron 绘制为 SVG path（见「图标 SVG path 清单」）
2. 颜色值按映射表替换
3. 保留值编辑功能（`edit_state`）——Quel'Thalas spin_button 有完整编辑逻辑，设置页的 StepperWidget 不需要编辑功能，保留 `-`/`+` 步进逻辑

### 分段控件（SegmentedWidget）

**旧绘制**：`paint_segmented` in widget.rs:496-535
**替换为**：Quel'Thalas `tab_list.rs` → 提取 top-rounded card + 选中片滑动
**Fluent 关键值**：
- `CARD_RADIUS = 4.0`（旧实现=7 → **改为 4**）
- 选中片：`color_neutral_background1`（浅）/ `color_neutral_background6`（深）
- 标签：选中高亮=foreground1，未选中=foreground2

**步骤**：
1. 选中片从「圆角矩形」改为「仅顶部圆角」（`tab_list.rs` 的 `top_rounded_card` 逻辑）
2. 指示条滑动逻辑保留 `anim_v`（已有）

## 5. 文件变更模式（供低智模型抄）

每个控件替换遵循同一模式：

```
1. 在 widget.rs 找到对应的 paint_* 函数
2. 用「替换为」代码完整替换函数体
3. 如果函数引用了 layout 常量：
   - 圆角 → 直接写 Fluent DIP 值（4.0 等）
   - 字号 → 查本表直接写数值
4. 颜色值 → 查 FluentToken映射表.md 直接替换
5. 删除旧绘制代码（不保留两套）
6. 编译验证：cargo build -p sysoverlay-win
```

## 6. 红线（低智模型禁止修改）

- ❌ `on_click_toggle` / `on_click_segmented` 等交互处理（mod.rs）
- ❌ `apply_config` 数据流
- ❌ `Dispatch::Toggle` 等 Action 枚举
- ❌ `Spring { x, v }` 结构和 `motion.rs`
- ❌ `scrollbar.rs` 任何代码
- ❌ `cfg_ref.rs` 任何代码
- ❌ `WidgetState { anim_v, hover_t, press_t, ... }` 结构体字段

# 悬浮窗多矩形脏区渲染方案（实施规格书 · 基于真实代码逐行核对版）

> **文档性质**：可直接执行的实施规格。所有"改前"代码都是从当前仓库**逐字摘录**的，
> 行号是写作当日快照（2026-09-14，master @ 99cf093 之后）。行号漂移时按"函数名"定位。
> **实施者不需要做任何设计决策**，按 §5 步骤顺序粘贴即可。

---

## 0. 一句话目标

把上屏从"**每帧一个整窗宽的并集矩形**"（`Dirty::Rect(并集)` → 一次 `UpdateLayeredWindowIndirect`）
改为"**每帧 N 个连通分量矩形、逐矩形上传**"。只有一格变化时只上传那一格（~12KB），
不再拖带整窗（~77KB）。**顺带修复旧模型下"时钟每秒变化 → 脏区=整窗 → Rect 零收益"的退化**
（gdi.rs 文件头"适用边界"第 1 条），该条结论是单并集模型的产物，本方案使其过时。

**明确不做**：绘制逻辑、布局逻辑、Full 触发条件、帧指纹、watchdog、纪元机制全部原样。

## 1. 现状架构（读代码后的准确描述）

全部逻辑在 `sysoverlay/crates/win/src/gdi.rs`（下称 gdi.rs）。两条渲染路径：

### 1.1 GDI 路径（`render()` 的 else 分支，gdi.rs 626-723 行）

```
layout() → cells
  ↓ 帧指纹相同 → 整帧跳过（658-665 行）
compute_dirty(&cells, src_alpha) → (Dirty, changed)      // 677 行
  ↓ force_full / 尺寸变化 → dirty = Full, changed 全 true // 680-683 行
renderer.paint(surface, ..., dirty.is_full(), changed)   // 691-698 行：GDI 只重画 changed 格
present(hwnd, &surface, w, h, alpha, &dirty)             // 700 行
```

### 1.2 D2D 路径（`render_d2d()`，gdi.rs 1130-1326 行）

```
layout() → cells
  ↓ 帧指纹 ⊕ ENGINE_HASH_XOR 相同 → 跳过（1177-1185 行）
compute_dirty_in(&PREV_CELLS_D2D, ..., ) → (dirty, _changed)  // 1190 行（changed 被忽略）
  ↓ force_full / 尺寸变化 → dirty = Full                       // 1193-1195 行
D2DSurface::bind(mem_dc) → clear() → paint_cells(全部)        // 1236-1238：整帧重绘进 DIB
upload_dib(hwnd, w, h, alpha, &dirty)                          // 1292 行
```

### 1.3 上屏函数（两处，结构相同）

- `present()`（946-1044 行，GDI 用）：`copy_rect_to_dib(bits, surface, &rect, ...)` 把画布脏区拷进 DIB，
  然后 `Full → UpdateLayeredWindow` / `Rect → UpdateLayeredWindowIndirect(prcDirty)`。
- `upload_dib()`（1046-1125 行，D2D 用）：D2D 直接画进 DIB，无需拷贝，直接 ULW / ULWIndirect。

两处的 ULWIndirect 块**各自内联了一份、参数逐字相同**（gdi.rs 头部第 3 条适用边界明确要求
"任何新增上传路径都照抄这两处"）。本方案把它们抽成一个公共函数，**参数语义一字不改**。

### 1.4 脏区计算（`compute_dirty_in`，gdi.rs 741-822 行，逐字现状）

```rust
fn compute_dirty_in(
    prev_cells: &OnceLock<Mutex<Vec<CellSig>>>,
    prev_alpha: &AtomicU8,
    cells: &[CellSig],
    src_alpha: u8,
) -> (Dirty, Vec<bool>) {
    let n = cells.len();
    let all = || vec![true; n];
    let prev_alpha_v = prev_alpha.load(AtomicOrdering::Relaxed);
    let prev = prev_cells.get_or_init(|| Mutex::new(Vec::new()));
    let Ok(mut prev) = prev.lock() else {
        return (Dirty::Full, all());
    };
    if prev_alpha_v != src_alpha || prev.len() != n {
        *prev = cells.to_vec();
        prev_alpha.store(src_alpha, AtomicOrdering::Relaxed);
        return (Dirty::Full, all());
    }
    let mut union: Option<RECT> = None;                 // ← 单并集，问题根源
    let mut force_full = false;
    let mut changed = vec![false; n];
    for (i, (a, b)) in cells.iter().zip(prev.iter()).enumerate() {
        if a.x != b.x || a.y != b.y {
            force_full = true;                           // 布局漂移
            break;
        }
        if a.hash != b.hash {
            changed[i] = true;
            let r = RECT {                               // 包围盒并入并集
                left: a.bbox_x,
                top: a.y,
                right: a.bbox_x + a.w,
                bottom: a.y + a.h,
            };
            union = Some(match union {
                Some(u) => RECT {
                    left: u.left.min(r.left),
                    top: u.top.min(r.top),
                    right: u.right.max(r.right),
                    bottom: u.bottom.max(r.bottom),
                },
                None => r,
            });
        }
    }
    *prev = cells.to_vec();                              // ⚠️ 无条件推进（见 §5.4）
    prev_alpha.store(src_alpha, AtomicOrdering::Relaxed);
    if force_full {
        return (Dirty::Full, all());
    }
    match union {
        Some(u) => {
            // 邻接传播至不动点（cell ≤ 10，代价可忽略）
            loop { /* changed 相交扩散，略——语义必须保留，见 §5.2 */ }
            (Dirty::Rect(u), changed)
        }
        // 有 cell 内容变化 → 上传其并集；否则（理论不可达）保守整窗
        None => (Dirty::Full, all()),
    }
}
```

**两个关键事实**（实施者必须理解）：

1. **`changed` 位图有两个消费者**：① 上传（并集矩形）；② GDI `paint` 跳过未变化格。
   邻接传播把"与变化格相交的邻居"也标记为 changed——这是 **paint 正确性**要求
   （变化格 `clear_rect` 会擦掉邻居墨迹，邻居必须连带重画），**不是**上传要求
   （邻居内容没变，重画出的像素与上一帧相同，无需上传）。所以本方案：
   **传播保留原样（服务 paint），上传矩形改用"内容变化格"的连通分量（更小）**。
2. **`*prev = cells.to_vec()` 在上屏之前无条件执行**（789 行）。上屏失败后调用方虽然
   回滚帧指纹，但下一帧 prev == 当前 → 算出"无变化"。旧代码靠
   `None => Dirty::Full`（820 行）兜底恢复——**这行不是死代码，是失败自愈路径**。
   本方案把"无变化"改为"跳过上屏"，必须补 `NEEDS_FULL_REUPLOAD` 闸门（§5.4），
   否则一次 ULW 失败 = 窗口永久冻结。

## 3. 绝对禁止事项（每条都有真实事故背书，gdi.rs 头部与行内注释为证）

1. **`pptSrc` 必须 `POINT { x: 0, y: 0 }`**：它表示"窗口左上角在源 DC 中的对齐点"。
   写 `(r.left, r.top)` 与 `prcDirty` 叠加成 2× 偏移 → API 成功但贴错像素
   （2026-09-12"时钟冻结"事故，行内注释含对照实验）。多矩形**每个矩形**的
   `pptSrc` 都是 (0,0)，变的只是 `prcDirty`。
2. **`pptDst` 必须 `std::ptr::null()`**：传 `Some((0,0))` 每帧把窗口挪回原位（拖动弹回事故）。
3. **std Mutex 不可重入**：D2D 路径调 `upload_dib` 前必须 `drop(dib)`
   （1287-1290 行注释，2026-09-12 线程死锁事故）。本方案不改这段。
4. **`bbox_x` 不用 `x`**：右对齐格墨迹左溢（CellSig 文档 renderer.rs 253-258 行）。
5. **设置面板重绘必须整窗**：`take_force_full()` 是正确性要求（2026-09-09 局部 ULW
   在部分合成器上不生效），不是性能选择。
6. **alpha 变化必须整窗**：全局 alpha 混在每像素里，局部上传残留旧 alpha。
7. **窗口尺寸变化必须整窗**：画布与 DIB 清零重建（675-676 行注释：非脏区会变全透明）。
8. **失败必须双保险**：回滚帧指纹（现有）+ `NEEDS_FULL_REUPLOAD`（新增，§5.4），缺一不可。
9. **`ENGINE_HASH_XOR`、watchdog、纪元机制不动**。

## 4. 数据结构改动

### 4.1 `Dirty` 枚举（gdi.rs 490-500 行整体替换）

```rust
/// 脏区：整窗，或若干连通分量矩形（可能边缘相碰，语义上互不重叠的"变化区域簇"）。
///
/// 多矩形语义：每个矩形独立走一次 `UpdateLayeredWindowIndirect(prcDirty=矩形)`，
/// `pptSrc` 恒为 (0,0)（见 §3.1）。空向量 = 本帧没有任何像素变化 → 跳过上屏
/// （DIB 与窗口显示本就一致，见 §1.4 事实 2 的闸门配套）。
/// 分量数超过 [`MAX_DIRTY_RECTS`] 时折叠为 `Full`，防病态布局下的系统调用风暴。
enum Dirty {
    Full,
    Rects(Vec<RECT>),
}

impl Dirty {
    fn is_full(&self) -> bool {
        matches!(self, Dirty::Full)
    }
}

/// 脏区分量上限。横条布局 ≤ 10 格（MetricRow 上限），8 绰绰有余；
/// 触顶说明布局病态或调用方漏判 Full 条件，保守整窗。
const MAX_DIRTY_RECTS: usize = 8;
```

### 4.2 新增静态闸门（放在 `DIRTY_DISABLED` 之后，gdi.rs 240 行附近）

```rust
/// 上屏失败后的整窗恢复闸门：任一 ULW/ULWIndirect 失败即置位，下一帧
/// `compute_dirty_in` 消费之并强制整窗。与"帧指纹回滚"配合使用：
/// 指纹回滚保证重试帧不被跳过，本闸门保证重试帧整窗覆盖（缺一会冻结，见 §1.4 事实 2）。
static NEEDS_FULL_REUPLOAD: AtomicBool = AtomicBool::new(false);
```

（`AtomicBool` 已在文件头部导入，37 行。）

### 5.2 步骤 2：重写 `compute_dirty_in`（741-822 行**整函数替换**）

```rust
/// [`compute_dirty`] 的存储参数化版本：GDI 与高画质 D2D 路径各持独立的
/// prev-cell 状态（两引擎画出的像素不同，跳过/脏区判定互不共享）。
fn compute_dirty_in(
    prev_cells: &OnceLock<Mutex<Vec<CellSig>>>,
    prev_alpha: &AtomicU8,
    cells: &[CellSig],
    src_alpha: u8,
) -> (Dirty, Vec<bool>) {
    let n = cells.len();
    let all = || vec![true; n];
    let prev_alpha_v = prev_alpha.load(AtomicOrdering::Relaxed);
    let prev = prev_cells.get_or_init(|| Mutex::new(Vec::new()));
    let Ok(mut prev) = prev.lock() else {
        return (Dirty::Full, all());
    };
    // 上屏失败恢复：上一帧 ULW 失败 → 本帧整窗覆盖（配套帧指纹回滚，见静态注释）。
    if NEEDS_FULL_REUPLOAD.swap(false, AtomicOrdering::Relaxed) {
        *prev = cells.to_vec();
        prev_alpha.store(src_alpha, AtomicOrdering::Relaxed);
        return (Dirty::Full, all());
    }
    if prev_alpha_v != src_alpha || prev.len() != n {
        *prev = cells.to_vec();
        prev_alpha.store(src_alpha, AtomicOrdering::Relaxed);
        return (Dirty::Full, all());
    }

    // 第一遍：找出**内容变化**格（hash 不同）。上传矩形只由这些格构成。
    let mut content_changed = vec![false; n];
    let mut force_full = false;
    for (i, (a, b)) in cells.iter().zip(prev.iter()).enumerate() {
        if a.x != b.x || a.y != b.y {
            // 布局漂移：旧位置像素必须随整窗上传清掉
            force_full = true;
            break;
        }
        if a.hash != b.hash {
            content_changed[i] = true;
        }
    }
    *prev = cells.to_vec();
    prev_alpha.store(src_alpha, AtomicOrdering::Relaxed);
    if force_full {
        return (Dirty::Full, all());
    }

    // 第二遍：邻接传播（语义与旧版一致，服务 GDI paint 跳格重画）：
    // 变化格包围盒（含阴影/描边外扩）相交的邻居也要重画——变化格 clear_rect
    // 会擦掉邻居墨迹。传播只扩 `changed`，**不扩上传矩形**：邻居内容没变，
    // 重画出的像素与上一帧相同，无需上传（两引擎的字体渲染都是确定性的）。
    let mut changed = content_changed.clone();
    loop {
        let mut grew = false;
        for i in 0..n {
            if !changed[i] {
                continue;
            }
            for j in 0..n {
                if changed[j] || i == j {
                    continue;
                }
                if cells_intersect(&cells[i], &cells[j]) {
                    changed[j] = true;
                    grew = true;
                }
            }
        }
        if !grew {
            break;
        }
    }

    // 连通分量：把**内容变化**格按包围盒相交聚成簇，每簇一个 bbox 并集矩形。
    // 与旧"单一并集"的本质区别：两簇之间的空隙不再被捎带上传。
    // （不同簇的矩形可能相交——重叠上传无害：拷的是同一份 DIB 内容，无需去重。）
    let rects = dirty_components(cells, &content_changed);
    if rects.len() > MAX_DIRTY_RECTS {
        return (Dirty::Full, all());
    }
    (Dirty::Rects(rects), changed)
}
```

> 与旧版的行为差异清单（评审用）：
> ① 旧版并集由"内容变化格"构成（768-787 行），传播只扩 changed 不扩并集——本版语义一致，
>   只是把"一个并集"换成"逐簇矩形"，空隙不再上传；
> ② 旧版"无变化 → Full"（820 行）→ 本版"无变化 → `Rects(vec![])` 跳过上屏"，
>   其失败自愈职责由 `NEEDS_FULL_REUPLOAD` 接管；
> ③ 其余 Full 条件逐字保留。

### 5.3 步骤 3：新增 `dirty_components`（放在 `cells_intersect` 之后，约 827 行后）

```rust
/// 把内容变化格按包围盒相交关系聚成连通分量，返回每簇的 bbox 并集矩形。
/// 并查集实现；cell ≤ 10，O(n²) 可忽略。
fn dirty_components(cells: &[CellSig], changed: &[bool]) -> Vec<RECT> {
    let n = cells.len();
    if n == 0 {
        return Vec::new();
    }
    let mut parent: Vec<usize> = (0..n).collect();
    fn find(p: &mut [usize], mut x: usize) -> usize {
        while p[x] != x {
            p[x] = p[p[x]];
            x = p[x];
        }
        x
    }
    for i in 0..n {
        if !changed[i] {
            continue;
        }
        for j in (i + 1)..n {
            if changed[j] && cells_intersect(&cells[i], &cells[j]) {
                let (ri, rj) = (find(&mut parent, i), find(&mut parent, j));
                if ri != rj {
                    parent[ri] = rj;
                }
            }
        }
    }
    // 归组：root → bbox 并集。包围盒用 bbox_x（见 §3.4，右对齐格墨迹左溢）。
    let mut acc: Vec<(usize, RECT)> = Vec::new();
    for i in 0..n {
        if !changed[i] {
            continue;
        }
        let r = RECT {
            left: cells[i].bbox_x,
            top: cells[i].y,
            right: cells[i].bbox_x + cells[i].w,
            bottom: cells[i].y + cells[i].h,
        };
        let root = find(&mut parent, i);
        match acc.iter_mut().find(|(root0, _)| *root0 == root) {
            Some((_, rect)) => {
                rect.left = rect.left.min(r.left);
                rect.top = rect.top.min(r.top);
                rect.right = rect.right.max(r.right);
                rect.bottom = rect.bottom.max(r.bottom);
            }
            None => acc.push((root, r)),
        }
    }
    acc.into_iter().map(|(_, rect)| rect).collect()
}
```

### 5.4 步骤 4：新增公共 ULWIndirect 函数（放在 `upload_dib` 之前，约 1045 行处）

把 present（1004-1032 行）与 upload_dib（1091-1115 行）**逐字相同**的 ULWIndirect
内联块抽出，原注释随迁：

```rust
/// 对单个脏矩形执行 `UpdateLayeredWindowIndirect`。
///

/// `pptSrc` 语义 = 「窗口左上角在 hdcSrc 中的对齐点」。整窗 DIB 的正确值是 (0,0)。
/// 旧代码写 (r.left, r.top)，与窗口坐标的 prcDirty 叠加后源像素被 2× 偏移——

/// **本函数是全项目唯一 ULWIndirect 出口**（gdi.rs 头部适用边界第 3 条：
/// 任何新增上传路径必须照抄本函数，禁止另写）。
#[allow(clippy::too_many_arguments)]
unsafe fn ulw_indirect_rect(
    hwnd: HWND,
    screen_dc: HDC,
    mem_dc: HDC,
    width: i32,
    height: i32,
    src_alpha: u8,
    bf: &BLENDFUNCTION,
    r: &RECT,
```

### 5.5 步骤 5：重写 GDI 路径 `present`（946-1044 行**整函数替换**）

```rust
/// 把 SoftwareSurface 上屏（DIB + UpdateLayeredWindow / UpdateLayeredWindowIndirect）。
///
/// `src_alpha` 为全局恒定 alpha（透明度 × 悬停系数，0..=255）。
/// `dirty` 决定上屏方式（A1/A2）：
/// - `Dirty::Full` 或 `AAXSYSPULSE_NODIRTY=1` → 整窗拷贝 + 经典 `UpdateLayeredWindow`。
/// - `Dirty::Rects(rects)` → 逐矩形拷进 DIB + 逐矩形 ULWIndirect；空列表 = 无像素变化，
///   跳过上屏（DIB 与窗口内容本就一致）。
/// 返回 false = 上屏失败（调用方回滚帧指纹；NEEDS_FULL_REUPLOAD 保证下帧整窗恢复）。
#[allow(clippy::too_many_arguments)]
fn present(
    hwnd: HWND,
    surface: &SoftwareSurface,
    width: i32,
    height: i32,
    src_alpha: u8,
    dirty: &Dirty,
) -> bool {
    unsafe {
        let screen_dc = GetDC(hwnd);
        if screen_dc.is_invalid() {
            return false;
        }

        let dib = DIB.get_or_init(|| Mutex::new(DibCache::default()));
        let Ok(mut dib) = dib.lock() else {
            let _ = ReleaseDC(hwnd, screen_dc);
            return false;
        };
        let Some((mem_dc, bits)) = dib.get(screen_dc, width, height) else {
            drop(dib);
            let _ = ReleaseDC(hwnd, screen_dc);
            return false;
        };

        // pptDst 传 NULL：保持窗口当前位置。
        // 若传 Some((0,0))，UpdateLayeredWindow 会把窗口挪到该坐标——
        // 这正是旧版"一拖动就弹回原位"的元凶（每帧渲染都重置位置）。
        let sz = SIZE { cx: width, cy: height };
        let bf = BLENDFUNCTION {
            BlendOp: windows::Win32::Graphics::Gdi::AC_SRC_OVER as u8,
            BlendFlags: 0,
            SourceConstantAlpha: src_alpha,
            AlphaFormat: windows::Win32::Graphics::Gdi::AC_SRC_ALPHA as u8,
        };

        let ok = if *DIRTY_DISABLED || matches!(dirty, Dirty::Full) {
            // A2 整窗拷贝（历史：187KB 中间拷贝在 Full 帧不可避免）
            let rect = RECT { left: 0, top: 0, right: width, bottom: height };
            copy_rect_to_dib(bits, surface, &rect, width, height);
            let src_pt = POINT::default();
            UpdateLayeredWindow(
                hwnd,
                screen_dc,
                None,
                Some(&sz),
                mem_dc,
                Some(&src_pt),
                COLORREF(0),
                Some(&bf as *const BLENDFUNCTION),
                windows::Win32::UI::WindowsAndMessaging::ULW_ALPHA,
            )
            .is_ok()
        } else if let Dirty::Rects(rects) = dirty {
            if rects.is_empty() {
                true // 无像素变化：跳过上屏（DIB 与窗口显示一致）
            } else {
                // A2：先把每个脏矩形从画布拷进 DIB（DIB 其余区域保留旧帧，
                // 与窗口显示一致），再逐矩形 ULWIndirect。拷贝全部先行，
                // 与上传解耦：任一矩形上传失败不影响 DIB 的完整性。
                for r in rects {
                    copy_rect_to_dib(bits, surface, r, width, height);
                }
                let mut all_ok = true;
                for r in rects {
                    if !ulw_indirect_rect(hwnd, screen_dc, mem_dc, width, height, src_alpha, &bf, r) {
                        all_ok = false;
                        break; // 失败即止：闸门保证下一帧整窗恢复
                    }
                }
                all_ok
            }
        } else {
            false
        };
        if !ok {
            NEEDS_FULL_REUPLOAD.store(true, AtomicOrdering::Relaxed);
            crate::probe::log("present: UpdateLayeredWindow failed");
        }

        // P2：不删除 mem_dc / bitmap —— 它们留在 DIB 缓存里逐帧复用。
        let _ = ReleaseDC(hwnd, screen_dc);
        ok
    }
}
```

### 5.6 步骤 6：重写 D2D 路径 `upload_dib`（1046-1125 行**整函数替换**）

```rust
/// 把已绘制好的 DIB（mem_dc）上传到分层窗口（高画质 D2D 路径用）。
///
/// D2D 直接写进 DIB 的预乘 BGRA 比特，所以无需 `copy_rect_to_dib`——
/// 只需把 DIB 上屏。`dirty` 决定上屏方式：
/// - `Dirty::Full` 或 `AAXSYSPULSE_NODIRTY=1` → 经典 `UpdateLayeredWindow`。
/// - `Dirty::Rects(rects)` → 逐矩形 `UpdateLayeredWindowIndirect`；空列表 = 跳过上屏。
/// 返回 false = 上屏失败（调用方应回滚帧指纹，否则相同内容帧会被跳过 → 冻结）。
unsafe fn upload_dib(hwnd: HWND, width: i32, height: i32, src_alpha: u8, dirty: &Dirty) -> bool {
    let screen_dc = GetDC(hwnd);
    if screen_dc.is_invalid() {
        return false;
    }
    let dib = DIB.get_or_init(|| Mutex::new(DibCache::default()));
    let Ok(mut dib) = dib.lock() else {
        let _ = ReleaseDC(hwnd, screen_dc);
        return false;
    };
    let Some((mem_dc, _bits)) = dib.get(screen_dc, width, height) else {
        drop(dib);
        let _ = ReleaseDC(hwnd, screen_dc);
        return false;
    };
    let bf = BLENDFUNCTION {
        BlendOp: windows::Win32::Graphics::Gdi::AC_SRC_OVER as u8,
        BlendFlags: 0,
        SourceConstantAlpha: src_alpha,
        AlphaFormat: windows::Win32::Graphics::Gdi::AC_SRC_ALPHA as u8,
    };
    // 卡死探针（2026-09-12 13:40 事故）：渲染线程最后日志停在 PAINT-DONE，
    // 唯一剩余阻塞点在 upload_dib 内部（GetDC / DIB.lock / ULW）。
    crate::probe::log_lazy(|| format!("upload-begin {}x{} dirty={}", width, height, fmt_dirty(dirty)));
    let ok = if *DIRTY_DISABLED || matches!(dirty, Dirty::Full) {
        let sz = SIZE { cx: width, cy: height };
        let src_pt = POINT::default();
        UpdateLayeredWindow(
            hwnd,
            screen_dc,
            None,
            Some(&sz),
            mem_dc,
            Some(&src_pt),
            COLORREF(0),
            Some(&bf as *const BLENDFUNCTION),
            windows::Win32::UI::WindowsAndMessaging::ULW_ALPHA,
        )
        .is_ok()
    } else if let Dirty::Rects(rects) = dirty {
        if rects.is_empty() {
            true // 无像素变化：跳过上屏（DIB 与窗口显示一致）
        } else {
            let mut all_ok = true;
            for r in rects {
                if !ulw_indirect_rect(hwnd, screen_dc, mem_dc, width, height, src_alpha, &bf, r) {
                    all_ok = false;
                    break;
                }
            }
            all_ok
        }
    } else {
        false
    };
    if !ok {
        NEEDS_FULL_REUPLOAD.store(true, AtomicOrdering::Relaxed);
        crate::probe::log("upload_dib: UpdateLayeredWindow failed");
    }
    crate::probe::log_lazy(|| format!("upload-end ok={ok}"));
    let _ = ReleaseDC(hwnd, screen_dc);
    ok
}
```

```rust
/// 探针用脏区摘要："Full" / "None(skip)" / "Rects(n=2, (l,t,r,b) (l,t,r,b))"。
fn fmt_dirty(dirty: &Dirty) -> String {
    match dirty {
        Dirty::Full => "Full".into(),
        Dirty::Rects(rs) if rs.is_empty() => "None(skip)".into(),
        Dirty::Rects(rs) => format!(
            "Rects(n={}, {})",
            rs.len(),
            rs.iter()
                .map(|r| format!("({},{},{},{})", r.left, r.top, r.right, r.bottom))
                .collect::<Vec<_>>()
                .join(" ")
        ),
    }
}
```

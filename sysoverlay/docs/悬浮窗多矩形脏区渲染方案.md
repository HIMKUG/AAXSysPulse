# 悬浮窗多矩形脏区渲染方案（实施规格书）

> **文档性质**：可执行的实施规格。目标读者是负责实施的 AI/开发者。
> 按"实施步骤"一节逐条执行即可，不需要自行设计方案。
> **行号是写作时的快照，可能漂移；行号对不上时一律按"函数名/代码片段"定位。**

---

## 0. 一句话目标

把悬浮窗的上屏从"**每帧一个整窗宽的并集矩形**"改成"**每帧 N 个不相交的小矩形、逐矩形上传**"，
让只有一格变化时只上传那一格（~12KB），而不是整窗（~77KB）。

**不做**任何其它重构。绘制逻辑、布局逻辑、Full 触发条件全部保持原样。

---

## 1. 背景：为什么现在的"脏区"会退化成整窗

### 1.1 现有上传模型

文件：`sysoverlay/crates/win/src/gdi.rs`（下称 gdi.rs）。

现在的脏区只有两种形态（gdi.rs 约 491 行）：

```rust
/// 脏区：整窗或子矩形。
enum Dirty {
    Full,
    Rect(RECT),          // ← 只有一个矩形：所有变化单元格的并集
}
```

`compute_dirty_in()`（gdi.rs 约 741-822 行）算出脏区：

1. 逐单元格比对内容哈希（`CellSig.hash`），得出 `changed[i]`；
2. **邻接传播**：变化格的包围盒（含阴影/描边外扩）若与相邻格相交，邻居也被标记为变化（不动点迭代）；
3. 把所有 changed 格的包围盒**求并集成一个矩形**返回 `Dirty::Rect(并集)`。

### 1.2 为什么必然退化成整窗

悬浮窗各单元格的变化节奏是**错开**的：

| 单元格 | 变化节奏 |
|---|---|
| Util（一位小数后） | 每次提交，1.5~4.5s |
| 网速 | 每 2s |
| 功耗 | 每 3s |
| 时钟 | 每 1s |

几乎每个提交周期至少一格在变。**并集矩形从"最左变化格"横跨到"最右变化格"**，
中间没变的格子被捎带上传。实测（`seg_upload pct=` 探针）长期 pct≈100%，
即"脏区渲染"在物理上已经等于整窗上传。

### 1.3 为什么多矩形是安全的（正确性论证，实施前必读）

上传的本质约束只有一个：

> **DIB（源位图）中某区域的内容 == 窗口当前显示的内容**，除了本次要上传的脏区。

- 单矩形上传时：并集**内部**的空隙像素被重传，但传的是和屏幕上一样的像素（没变过），所以无所谓。
- 多矩形上传时：空隙**不传**。空隙像素在 DIB 里是旧值、在屏幕上也是旧值，两者本来就相等。

DIB 与屏幕的一致性由现有的 **Full 触发条件**维护（alpha 变化 / 布局漂移 / 窗口尺寸变化 /
设置面板强制整窗 / 上屏失败回滚）——这些全部原样保留。
**所以多矩形没有引入任何新的正确性风险面，只是少传了字节。**

## 4. 绝对禁止事项（历史事故清单，每一条都出过真实事故）

1. **`pptSrc` 必须是 `POINT { x: 0, y: 0 }`**。它表示"窗口左上角在源 DC 中的对齐点"，
   整窗 DIB 就写 (0,0)。写成 `(r.left, r.top)` 会与 `prcDirty` 叠加成 2× 偏移，
   API 返回成功但贴错像素——2026-09-12"时钟冻结"事故的根因。
   多矩形沿用同一语义：**每个矩形的 `pptSrc` 仍然是 (0,0)，变的只是 `prcDirty`**。
2. **`pptDst` 必须传 `null`**。传 `Some((0,0))` 会把窗口挪回原位——"一拖动就弹回"事故。
3. **std Mutex 不可重入**。D2D 路径在调 `upload_dib` 前必须 `drop(dib)`
   （upload_dib 内部会重新加锁）。2026-09-12 悬浮窗线程死锁事故。
4. **上屏失败必须留下"下一帧强制 Full"的痕迹**。现有机制是回滚帧指纹
   （`LAST_FRAME_HASH.store(u64::MAX)`）。本方案新增 `NEEDS_FULL_REUPLOAD`
   闸门（§5.6），**两者都要**，缺一不可。原因见 §5.6。
5. **设置面板触发的重绘必须整窗**（`take_force_full()`）。2026-09-09 实测：部分合成器上
   局部 ULW 对"像素类"变更不生效。别试图"优化"它。
6. **alpha 变化必须整窗**。分层窗口的全局 alpha 混在每个像素里，局部上传会残留旧 alpha。
7. **窗口尺寸变化后必须整窗**（画布与 DIB 被清零重建，局部上传会让非脏区变全透明）。
8. **包围盒用 `bbox_x` 不用 `x`**。右对齐数值格的墨迹向左溢出绘制原点，
   用 `x` 会在数值变化时留下左侧幽灵像素。
9. **`AAXSYSPULSE_NODIRTY=1` 环境变量逃生门必须继续生效**（`DIRTY_DISABLED`）。

### 步骤 1：改 `Dirty` 枚举

**位置**：gdi.rs 约 491-500 行。

改前：

```rust

    Full,
    Rect(RECT),
}

}
```

改后：

```rust
/// 脏区：整窗，或若干**互不相交**（允许边缘相碰）的子矩形。
///
/// 多矩形语义：每个矩形独立走一次 `UpdateLayeredWindowIndirect(prcDirty=矩形)`。
/// 空向量 = 本帧没有任何像素变化，跳过上屏（窗口显示的已是最新内容）。
/// 分量数超过 `MAX_DIRTY_RECTS` 时调用方必须折叠为 `Full`（防病态布局下的系统调用风暴）。
enum Dirty {
    Full,
    Rects(Vec<RECT>),
}

impl Dirty {
    fn is_full(&self) -> bool {
        matches!(self, Dirty::Full)
    }
}

/// 脏区分量上限：超过即折叠整窗。正常横条 ≤ 10 格，8 绰绰有余；
/// 触顶说明布局病态（或调用方漏传 Full 条件），保守整窗。
const MAX_DIRTY_RECTS: usize = 8;
```

改完立即 `cargo build`。此时编译器会在若干 match 处报错（`Dirty::Rect` 不存在了），
**先别修**，继续步骤 2-4 把所有站点一起改完，最后统一编译。

```rust
    let mut force_full = false;
    let mut changed = vec![false; n];
    for (i, (a, b)) in cells.iter().zip(prev.iter()).enumerate() {
        if a.x != b.x || a.y != b.y {
            // 布局漂移：旧位置像素必须随整窗上传清掉
            force_full = true;
            break;
        }
        if a.hash != b.hash {
            changed[i] = true;
        }
    }
    *prev = cells.to_vec();
    prev_alpha.store(src_alpha, AtomicOrdering::Relaxed);
    if force_full {
        return (Dirty::Full, all());
    }

    // 邻接传播（语义与旧版逐字节一致）：变化格的包围盒（含阴影/描边外扩）若与
    // 邻居相交，邻居也标记为 changed——GDI 路径 paint 跳过未标记格时，
    // 被变化格 clear_rect 擦掉墨迹的邻居必须连带重画，否则出现幽灵像素。
    // 传播至不动点（cell ≤ 10，代价可忽略）。
    loop {
        let mut grew = false;
        for i in 0..n {
            if !changed[i] {
                continue;
            }
            for j in 0..n {
                if changed[j] || i == j {
                    continue;
                }
                if cells_intersect(&cells[i], &cells[j]) {
                    changed[j] = true;
                    grew = true;
                }
            }
        }
        if !grew {
            break;
        }
    }

    // 连通分量分组：把相交的 changed 格聚成一簇，每簇输出一个包围盒矩形。
    // 与旧"单一并集"的本质区别：两簇之间的**空隙不再被捎带上传**。
    // （簇矩形的并集可能仍相交——如两簇分别位于第三簇两侧的空隙里——
    //   重叠上传无害：拷的是同一份 DIB 内容。无需再做矩形级去重。）
    let rects = dirty_components(cells, &changed);
    if rects.len() > MAX_DIRTY_RECTS {
        // 病态布局保守整窗（防 ULWIndirect 系统调用风暴）
        return (Dirty::Full, all());
    }
    (Dirty::Rects(rects), changed)
```

### 步骤 3：新增连通分量函数（放在 `compute_dirty_in` 之后）

```rust
/// 把 changed 格按包围盒相交关系聚成连通分量，返回每簇的包围盒矩形。
///
/// 算法：并查集。先对 i<j 且 `cells_intersect` 的 changed 对做 union，
/// 再按根归组、对每簇求 bbox 并集。复杂度 O(n²)，n ≤ 10，可忽略。
fn dirty_components(cells: &[CellSig], changed: &[bool]) -> Vec<RECT> {
    let n = cells.len();
    if n == 0 {
        return Vec::new();
    }
    // 并查集（路径压缩 + 按秩无所谓，n 太小）
    let mut parent: Vec<usize> = (0..n).collect();
    fn find(p: &mut Vec<usize>, x: usize) -> usize {
        let mut x = x;
        while p[x] != x {
            p[x] = p[p[x]];
            x = p[x];
        }
        x
    }
    for i in 0..n {
        if !changed[i] {
            continue;
        }
        for j in (i + 1)..n {
            if changed[j] && cells_intersect(&cells[i], &cells[j]) {
                let ri = find(&mut parent, i);
                let rj = find(&mut parent, j);
                if ri != rj {
                    parent[ri] = rj;
                }
            }
        }
    }
    // 归组：root → (min_left, min_top, max_right, max_bottom)
    let mut acc: Vec<(usize, RECT)> = Vec::new();
    for i in 0..n {
        if !changed[i] {
            continue;
        }
        let r = RECT {
            left: cells[i].bbox_x,
            top: cells[i].y,
            right: cells[i].bbox_x + cells[i].w,
            bottom: cells[i].y + cells[i].h,
        };
        let root = find(&mut parent, i);
        match acc.iter_mut().find(|(root0, _)| *root0 == root) {
            Some((_, rect)) => {
                rect.left = rect.left.min(r.left);
                rect.top = rect.top.min(r.top);
                rect.right = rect.right.max(r.right);
                rect.bottom = rect.bottom.max(r.bottom);
            }
            None => acc.push((root, r)),
        }
    }
    acc.into_iter().map(|(_, rect)| rect).collect()
}
```

### 步骤 4：新增 `NEEDS_FULL_REUPLOAD` 闸门 + `compute_dirty_in` 头部接入

**为什么必须有**：现在 `compute_dirty_in` 末尾无条件 `*prev = cells.to_vec()`——
prev 永远指向"刚算过的这帧"。如果本帧上屏失败，调用方回滚帧指纹让下一帧重试，
但下一帧 `compute_dirty_in` 一比对：prev == 当前 → 没有任何变化 → 返回空分量 →
跳过上屏 → **窗口永远冻结在旧画面**。

旧代码为什么没这个 bug？因为旧行为"无变化 → `None => Dirty::Full`"恰好充当了
失败恢复路径。本方案把"无变化"改成了"跳过上屏"，**必须补一个显式的恢复闸门**，
否则等于拆掉了唯一的失败自愈路径。

**位置**：gdi.rs 静态区（`PREV_CELLS_D2D` 附近，约 245 行后）新增：

```rust
/// 上屏失败后的整窗恢复闸门：任一 ULW/ULWIndirect 失败即置位，
/// 下一帧 compute_dirty_in 消费之并强制整窗（与帧指纹回滚配合使用）。
static NEEDS_FULL_REUPLOAD: AtomicBool = AtomicBool::new(false);
```

`compute_dirty_in` **头部**（拿到 `prev` 锁之后、比对之前）插入：

```rust
    // 上屏失败恢复：上一帧 ULW 失败 → 本帧强制整窗（见闸门注释）。
    if NEEDS_FULL_REUPLOAD.swap(false, AtomicOrdering::Relaxed) {
        *prev = cells.to_vec();
        prev_alpha.store(src_alpha, AtomicOrdering::Relaxed);
        return (Dirty::Full, all());
    }
```

```rust
    hwnd: HWND,

    width: i32,
    height: i32,
    src_alpha: u8,
    bf: &BLENDFUNCTION,
    r: &RECT,
) -> bool {
    // ✅ 根因修复（2026-09-12）：pptSrc 语义 =「窗口左上角在 hdcSrc 中的对齐点」，
    // 整窗 DIB 的正确值是 (0,0)。写 (r.left, r.top) 会与 prcDirty 叠加成 2× 偏移。
    let ppsrc = POINT { x: 0, y: 0 };
    // prcDirty 非空时 psize/pptDst 被忽略；psize 给整窗尺寸是规范姿势。
    let psize = SIZE { cx: width, cy: height };
    let prc = RECT { left: r.left, top: r.top, right: r.right, bottom: r.bottom };
    let info = UPDATELAYEREDWINDOWINFO {
        cbSize: std::mem::size_of::<UPDATELAYEREDWINDOWINFO>() as u32,
        hdcDst: screen_dc,
        pptDst: std::ptr::null(),
        psize: &psize as *const SIZE,
        hdcSrc: mem_dc,
        pptSrc: &ppsrc as *const POINT,
        crKey: COLORREF(0),
        pblend: bf as *const BLENDFUNCTION,
        dwFlags: windows::Win32::UI::WindowsAndMessaging::ULW_ALPHA,
        prcDirty: &prc as *const RECT,
    };
    UpdateLayeredWindowIndirect(hwnd, &info).as_bool()
}
```

（若 `HDC` 类型名与文件内现有写法不一致，以文件内现有签名为准。）

### 步骤 6：改 D2D 路径的 `upload_dib`（约 1051 行）

D2D 直接画进 DIB，无需拷贝。同样把 `ok = ...` 段替换：

```rust
    let ok = if *DIRTY_DISABLED || matches!(dirty, Dirty::Full) {
        let sz = SIZE { cx: width, cy: height };
        let src_pt = POINT::default();
        UpdateLayeredWindow(
            hwnd,
            screen_dc,
            None,
            Some(&sz),
            mem_dc,
            Some(&src_pt),
            COLORREF(0),
            Some(&bf as *const BLENDFUNCTION),
            windows::Win32::UI::WindowsAndMessaging::ULW_ALPHA,
        )
        .is_ok()
    } else if let Dirty::Rects(rects) = dirty {
        if rects.is_empty() {
            true // 无像素变化，跳过上屏（DIB 与窗口一致）
        } else {
            let mut all_ok = true;
            for r in rects {
                if !ulw_indirect_rect(hwnd, screen_dc, mem_dc, width, height, src_alpha, &bf, r) {
                    all_ok = false;
                    break;
                }
            }
            all_ok
        }
    } else {
        false
    };
    if !ok {
        NEEDS_FULL_REUPLOAD.store(true, AtomicOrdering::Relaxed);
        crate::probe::log("upload_dib: UpdateLayeredWindow failed");
    }
```

原 `upload_dib` 里对单矩形的 ULWIndirect 内联块整段删除（已被 `ulw_indirect_rect` 取代），
原有的 `pptSrc` 历史注释**搬进** `ulw_indirect_rect`（步骤 5 已含）。

### 步骤 7：更新探针日志（3 处 + 1 处统计）

所有 `match dirty { Dirty::Full => ..., Dirty::Rect(r) => ... }` 的格式化代码

```rust
fn fmt_dirty(dirty: &Dirty) -> String {
    match dirty {
        Dirty::Full => "Full".into(),
        Dirty::Rects(rs) if rs.is_empty() => "None(skip)".into(),
        Dirty::Rects(rs) => format!(
            "Rects(n={}, {})",
            rs.len(),
            rs.iter().map(|r| format!("({},{},{},{})", r.left, r.top, r.right, r.bottom))
                .collect::<Vec<_>>().join(" ")
        ),
    }
}
```

同时把 `seg_upload pct=` 统计（D2D 路径约 1296 行）改为**多矩形总面积占比**：

```rust
        let dirty_pct = match dirty {
            Dirty::Full => 100u64,
            Dirty::Rects(rs) => {
                let area: u64 = rs.iter()
                    .map(|r| ((r.right - r.left).max(0) as u64) * ((r.bottom - r.top).max(0) as u64))
                    .sum();
                (area * 100)
                    .checked_div((width.max(0) as u64) * (height.max(0) as u64))
                    .unwrap_or(100)
                    .min(100)
            }
        };
        perf::note_section(&format!("seg_upload pct={dirty_pct} n={}", match dirty {
            Dirty::Rects(rs) => rs.len(), _ => 1,
        }), t_upload);
```

## 7. 单元测试（完整给出，直接粘贴）

放 gdi.rs 文件底部 `#[cfg(test)] mod dirty_tests`。`compute_dirty_in` 是"存储参数化"
的（prev 状态通过参数传入），测试用**局部** OnceLock，互不污染：

```rust
#[cfg(test)]
mod dirty_tests {
    use super::*;

    fn cell(x: i32, hash: u64) -> CellSig {
        // bbox_x = x（左对齐简化）；text/color 等字段不参与脏比对，填默认即可
        CellSig {
            x,
            y: 8,
            w: 40,
            h: 28,
            bbox_x: x,
            right_align: false,
            hash,
            text: aaxsyspulse_core::units::StrBuf::new(),
            color: Default::default(),
            shade: Default::default(),
            shadow: false,
            outline: false,
            scale: 1.0,
        }
    }

    fn fresh_state() -> (OnceLock<Mutex<Vec<CellSig>>>, AtomicU8) {
        (OnceLock::new(), AtomicU8::new(0))
    }

    fn run(
        state: &(OnceLock<Mutex<Vec<CellSig>>>, AtomicU8),
        cells: &[CellSig],
    ) -> (Dirty, Vec<bool>) {
        compute_dirty_in(&state.0, &state.1, cells, 255)
    }

    #[test]
    fn first_frame_is_full() {
        let st = fresh_state();
        let (d, changed) = run(&st, &[cell(0, 1), cell(100, 2)]);
        assert!(d.is_full());
        assert!(changed.iter().all(|&c| c), "首帧必须全部重画");
    }

    #[test]
    fn two_far_changed_cells_yield_two_rects() {
        let st = fresh_state();
        run(&st, &[cell(0, 1), cell(100, 2), cell(300, 3)]); // 建立基线
        // 第 0 格与第 2 格变化（相距 300px，中间隔第 1 格）→ 2 个矩形
        let cells = [cell(0, 99), cell(100, 2), cell(300, 98)];
        let (d, changed) = run(&st, &cells);
        let Dirty::Rects(rs) = d else { panic!("应为 Rects") };
        assert_eq!(rs.len(), 2, "相距远的变化格不得合并: {rs:?}");
        assert!(rs[0].right <= rs[1].left, "矩形之间必须隔开空隙");
        assert!(changed[0] && changed[2] && !changed[1]);
    }

    #[test]
    fn adjacent_changed_cells_merge_into_one_rect() {
        let st = fresh_state();
        // 两格紧贴（0..40 与 40..80，包围盒相触）
        run(&st, &[cell(0, 1), cell(40, 2)]);
        let cells = [cell(0, 99), cell(40, 98)];
        let (d, _) = run(&st, &cells);
        let Dirty::Rects(rs) = d else { panic!("应为 Rects") };
        assert_eq!(rs.len(), 1, "相邻格必须并成一簇");
        assert_eq!((rs[0].left, rs[0].right), (0, 80));
    }

    #[test]
    fn no_change_yields_empty_rects_not_full() {
        let st = fresh_state();
        let cells = [cell(0, 1), cell(100, 2)];
        run(&st, &cells);
        let (d, _) = run(&st, &cells); // 同内容再来一帧
        let Dirty::Rects(rs) = d else { panic!("应为 Rects") };
        assert!(rs.is_empty(), "无变化必须是空矩形列表");
    }

    #[test]
    fn alpha_change_is_full() {
        let st = fresh_state();
        run(&st, &[cell(0, 1)]);
        let (d, _) = compute_dirty_in(&st.0, &st.1, &[cell(0, 1)], 128); // alpha 变了
        assert!(d.is_full());
    }

    #[test]
    fn position_drift_is_full() {
        let st = fresh_state();
        run(&st, &[cell(0, 1)]);
        let (d, _) = run(&st, &[cell(10, 1)]); // x 漂移
        assert!(d.is_full());
    }

    #[test]
    fn too_many_components_folds_to_full() {
        let st = fresh_state();
        // 10 个互相远离的格子，全部变化 → 10 簇 > MAX_DIRTY_RECTS(8) → Full
        let base: Vec<CellSig> = (0..10).map(|i| cell(i * 100, i as u64 + 1)).collect();
        run(&st, &base);
        let changed: Vec<CellSig> = (0..10).map(|i| cell(i * 100, i as u64 + 100)).collect();
        let (d, _) = run(&st, &changed);
        assert!(d.is_full(), "超过 MAX_DIRTY_RECTS 必须折叠整窗");
    }
}
```

> 若 `CellSig` 字段与上面构造器不符（未来加了字段），按编译器提示补齐；
> `StrBuf::new()` 来自 `aaxsyspulse_core::units`。

## 8. 验收标准（全部满足才算完成）

1. `cargo build --release` 零错误；`cargo test --release` 全绿（含新增 7 个测试）。

   - 时钟跳秒帧：`dirty=Rects(n=1, ...)` 且矩形宽度 ≈ 时间格宽度（几十像素）；
   - 只有 Util 变化的提交帧：`n=1`，宽度 ≈ Util 格宽；
   - Util+功耗同帧变化：`n=2`，两矩形之间有间隙。
3. **性能验收**：`seg_upload pct=` 从改造前的长期 ≈100 降到 **≤40**（稳态空闲），
   `n=` 通常 1~3。

   - 悬浮窗数值正常跳动，无残影/幽灵像素（尤其右对齐数值格左缘）；
   - 拖动悬浮窗不弹回原位；
   - 设置面板改颜色/字重后立即生效（走 force_full）；
   - 透明度过渡动画正常；
   - 锁屏解锁、DPI 变化、D2D 失败回退 GDI 后画面正常。
5. **失败恢复**（人工模拟）：设 `AAXSYSPULSE_NODIRTY=1` 启动再关掉，
   或临时在 `ulw_indirect_rect` 里注入一次失败，确认下一帧走 Full、画面不冻结。
6. 观察日志无 `upload-end ok=false` 刷屏；出现 `Rects(n=0)`(skip) 属正常但不应高频
   （高频说明帧指纹误放行，回报分析）。

## 9. 回滚方案

- **一键回退**：环境变量 `AAXSYSPULSE_NODIRTY=1` 启动 → 全部走经典整窗 ULW，
  多矩形代码完全不参与。
- **代码回退**：本方案改动全部集中在 gdi.rs，`git revert` 单个提交即可。

## 10. 二期展望（本期明确不做）

- **D2D 部分重绘**：`clear()` + 全量 `paint_cells` 改为只清/画脏分量矩形。
  依赖 DWrite 确定性渲染（同输入同像素），收益是省亚毫秒级绘制时间，风险是
  DIB 残留语义，等一期稳定后评估。
- **DirectComposition 逐视觉合成**：每 cell 一个 DComp visual，彻底摆脱 ULW。
  对 485×40 的悬浮窗属于杀鸡用牛刀，仅在将来转 GPU 合成架构时考虑。
